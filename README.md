## 🚀 How to Use (3 Simple Steps)

### 1. First Launch
- Enter API ID & API Hash from https://my.telegram.org/apps
- Click "Save & Continue"
- **NEVER ASKED AGAIN!**

### 2. Setup
- Go to **Accounts** tab → Add accounts
- Click "Load All Groups"
- Done!

### 3. Broadcast (4 Steps)
1. **Select Accounts** (use Select All/Deselect All)
2. **Select Groups** (use Select All/Deselect All)
3. **Configure**:
   - Message text
   - Delay (1-300 seconds)
   - Auto-repeat (optional)
4. **Click "Create & Start Broadcast"**

**That's it!** Auto-saves everything, logs everything, handles everything.
